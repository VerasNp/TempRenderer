# ADR-007: Inicialização

## Contexto

É comum que projetos tenham um ponto de entrada e configuração.

## A ser considerado

### Composition root

Tendo um arquivo de entrada, como `main.cpp` é possível alí inicializar os "subsistemas" do renderizador, por exemplo o próprio render, gerenciamento de memória, file system e assim por diante a partir de um ponto único de entrada.

Tendo em mente isso ainda podemos utilizar uma ideia muito comum que é a de Singletons.
