# ADR-002: Precisão numérica

## Contexto

O renderizador lida com cálculos que exigem precisão geométrica, como a interseção de raio, cujo problema central é resolver um $\Delta$ (delta) de forma numericamente. Atualmente é utilizada a biblioteca auxiliar [KWP](https://codeberg.org/VerasNp/KWP), que define seu escalar (`Scalar`) no momento da build.

Nem todo dado numérico do renderizador tem os mesmos requisitos de precisão.Cálculos geométricos (interseção, transformações, normais) se beneficiam de maior precisão (ex: `double`), enquanto outros dados, como componentes decor, não precisam da mesma granularidade e podem usar tipos menores(ex: `uint8_t`) sem perda perceptível de qualidade, e com ganho de uso de memória e cache.

## A ser considerado

- Definição via CMake de maneira global e uso de Scalar global;
- Definição hard-coded: Chances de perda de precisões, caso os tipos não batam com o escolhido da biblioteca
