# ADR-007: Inicialização e configuração

## Contexto

É comum que projetos tenham um ponto de entrada e configuração.

## A ser considerado

### Composition root

Tendo um arquivo de entrada, como `main.cpp` é possível alí inicializar os "subsistemas" do renderizador, por exemplo o próprio render, gerenciamento de memória, file system e assim por diante a partir de um ponto único de entrada.

### Arquivo de configuração

Outras configurações como tamanho da tela serão explicitadas em um arquivo externo `config.toml`, para isso será utilizada a biblioteca [tomlplusplus](https://github.com/marzer/tomlplusplus).

#### Uma abstração

Dado que a configuração de objetos em toml se demonstra complicada e pode ser um forte impeditivo para objetos mais complexos outro formato melhor, como por exemplo arquivos `.json`, e para isso pode ser necessário usar outra forma de leitura desses arquivos, logo outro tipo de biblioteca. A aplicação assim deve evitar ficar presa a um tipo de biblioteca para não gerar acoplamento.

Dado o problema apresentado vai ser implementado o que o esquema de ports and adapters usa. Tendo assim um Port para um parser e assim seus adapters seja para um parser de TOML como um parser de JSON.
